# Licensing

This repository is prepared as a commercial **Portfolio CMS** product template.

## Intended distribution model

- Sell per-license / per-customer deployments (typical: one Hostinger app + one Supabase project)
- Customer public websites display **their** brand and content only
- Vendor product name (“Portfolio CMS”) may appear in admin chrome and documentation, not as the customer’s public brand

## What licensees receive

- Source code for the portfolio website and admin CMS
- Documentation for installation, Hostinger deployment, and admin use
- Schema migrations and optional demo seed

## What licensees must not do (recommended commercial terms)

- Resell the unmodified product as their own competing CMS SaaS without an agency/reseller agreement
- Remove copyright / license notices required by your commercial agreement
- Redistribute private credentials or another customer’s content

## Customer data ownership

All portfolio content created by a customer in their Supabase project belongs to that customer.

## Multi-tenant / plan roadmap

Schema includes `plan_tier` values (`demo`, `starter`, `pro`, `agency`) for future packaging. This release does not enforce billing.
